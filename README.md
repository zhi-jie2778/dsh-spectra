# 界面美化 · dsh-ui-beautify

给 DeepSeek Harness Web GUI 的全参数外观定制插件：**一个总开关**、**六套内置方案**、**无限自定义**、**可分享的配置码**。

装好之后它什么都不改——你要先在 **设置 → 界面美化** 里打开总开关，界面才会开始变化；关掉总开关，界面立刻回到原版，不留痕迹。

---

## 功能

### 开箱即用的六套方案（一键切换，浅色 / 深色各一套）

| 方案 | 气质 |
| --- | --- |
| 苹果玻璃 | 磨砂毛玻璃、大圆角、柔和阴影 |
| 赛博霓虹 | 深色底 + 霓虹紫青 + 发光边框 |
| 糖果极光 | 梦幻渐变、光晕、弹性动效 |
| 极简瑞士 | 高对比、细线框、大量留白 |
| 暖色纸感 | 莫兰迪低饱和、护眼暖调 |
| 终端复古 | 荧光绿、等宽字体、CRT 味道 |

### 参数

- **总开关**：关闭后完全还原，CSS 与属性一并移除。
- **明暗**：自动跟随 DSH 主题，也可强制浅色 / 深色。
- **区域开关**：侧栏、对话、输入框、浮层、设置页、终端与预览、代码块、细节，八块独立开关。
- **颜色**：主色、辅色、画布、面板、次级面板、正文、次要文字、边框、两种气泡、代码块——浅色与深色各 11 项，全部带取色器与色值输入。
- **材质**：毛玻璃开关、模糊半径、面板透明度、边框强度、阴影强度。
- **动效**：悬停微交互、浮层进出场、消息进场、流式文字光效、输入框聚焦光晕、思考/执行呼吸、页面切换过渡，逐项 0–100% 强度。
- **布局**：圆角倍率、界面密度（等比缩放）。
- **背景**：纯色 / 渐变 / 图片（URL 或本地上传）/ 动态流动，另有模糊、压暗、饱和度、流动速度。
- **壁纸库**：上传过的图片都会留在库里，缩略图一点即换，当前那张带描边；鼠标悬停出现 `×` 可以删掉。设置里只记录图片编号，地址在每次打开时按当前端口重新生成，所以换端口、重启都不会失效。
- **分区着色**：侧栏、对话区、输入框三处可以各上一种底色，其余部分继续跟随主题。
- **细节**：自定义滚动条、主色光标、选中文字配色。
- **护眼模式**：低蓝光暖色滤镜，可设时段自动生效。
- **智能配色**：从壁纸里提取主色，生成配套配色。
- **我的方案**：保存整套设置、命名、一键切回、删除。
- **分享**：配置码（`UB1.…`）一键复制/粘贴，或导出 JSON 文件。
- **快捷键**：`Ctrl + Alt + B` 开关美化，`Shift + Alt + B` 循环切换内置方案。
- **恢复出厂**：一键回到原版（保留你保存的自定义方案）。

### 持久化

主题文档保存在 **`$DSH_HOME/ui-beautify/state.json`**（默认 `C:\Users\<你>\.dsh\ui-beautify\state.json`），同时在本机浏览器 `localStorage` 里存一份即时缓存。换浏览器、重启、升级都还在；上一次的文档会留作 `state.bak.json`。

## 安装

### 从 GitHub 克隆（推荐）

```bash
git clone https://github.com/<你的用户名>/dsh-ui-beautify.git
dsh plugin --profile desktop add link:<克隆目录的绝对路径>
```

Windows 上更省事的做法是用目录联接，这样以后 `git pull` 完不用重新安装：

```powershell
New-Item -ItemType Junction `
  -Path   "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-ui-beautify" `
  -Target "<克隆目录的绝对路径>"
```

### 手动两步

1. 把本目录放到 `<DSH_HOME>/profiles/<profile>/node_modules/dsh-ui-beautify`（可用目录联接 Junction / symlink）。
2. 在 `<DSH_HOME>/profiles/<profile>/cordis.patch.yml` 末尾追加：

```yaml
- insert:
    - id: ui-beautify
      name: dsh-ui-beautify
```

### 装完必须重启

**彻底退出 DSH 再重新打开**（托盘图标右键 → 退出；只点窗口右上角 × 可能只是隐藏到托盘）。Loader 只在启动时读取插件代码，而桌面端生产版没有刷新菜单，`Ctrl + R` 是无效的。重启后打开 **设置 → 界面美化**。

### 升级

```bash
git pull
```

然后同样彻底退出 DSH 重开一次。你的设置存在 `$DSH_HOME/ui-beautify/`，升级不会动它。

## 卸载

1. 在设置里关掉总开关（先还原外观）。
2. 从 `cordis.patch.yml` 删掉上面的 `insert` 块。
3. 删除 `node_modules/dsh-ui-beautify` 与 `$DSH_HOME/ui-beautify`。

## 兼容与边界

- 只做 **CSS 设计令牌覆盖 + 少量 DOM 属性**，不改任何 DSH 源码，不注入脚本到业务逻辑。
- 选择器只用 DSH 真实暴露的语义锚点：`[data-conversation-scroll]`、`[data-composer-seat]`、`[data-composer-card]`、`[data-content-phase]`、`[data-lexical-editor]`、`[data-ub-wall]` 等，**不依赖编译后的哈希类名**，所以 DSH 换版本也不会因为类名变化而失效。
- 壁纸只画在会话滚动容器上，侧栏、顶栏、输入框各自保持自己的表面。
- 只有模糊或饱和度真的不是中性值时，才会生成 `filter`；否则那一层不进 GPU 滤镜通道。
- 总开关关闭时样式表内容为空字符串，`<html>`/`<body>` 上的属性全部移除。
- 与其它皮肤插件共存时，本插件的令牌在 `body[data-ub-mode]` 上声明，优先级高于皮肤默认层；想完全交给别的皮肤，关掉本插件即可。
- 「界面密度」使用 `zoom`，会把整个界面等比缩放；若你的显示器有非整数缩放，建议保持 1.00。

## 诊断

设置里的「更多 → 诊断」有一个**重绘压力测试**按钮，会连续重绘壁纸图层 24 次，用来排查偶发的重绘异常。反馈问题时附上截图最有用。

宿主侧另有 `GET /plugins/dsh-ui-beautify/diagnostics`，返回版本、状态文件路径与最近的请求记录。

## 已知限制

- **对话区底色与壁纸互斥**：给对话区设了底色后，壁纸会自动让位（否则两张面互相盖住）。想要壁纸就把对话区底色点「跟随主题」。
- **桌面端没有页面刷新**：改了设置以外的任何东西（比如升级插件）都得彻底退出 DSH 重开。
- 只用语义锚点，如果 DSH 大版本改掉了某个 `data-*` 属性，相关区域会退回原样，不会报错。可以在 `lib/client.js` 里搜 `data-conversation-scroll` 之类的字符串快速定位。
- 「界面密度」用 `zoom` 实现，非整数显示缩放时建议保持 1.00。

## 开发

```bash
node test/smoke.mjs      # 主题引擎：预设、令牌、CSS、配置码、分区、跨模式配色
node test/wallpaper.mjs  # 壁纸库：id 契约、悬空指针修复、滤镜生成条件
node test/render.mjs     # 十个标签页 + 弹窗的完整渲染遍历
```

三个测试都只依赖 Node 自带模块，会自己 stub 掉浏览器全局，所以 `npm test` 不需要安装任何依赖，CI 里也是直接跑。

```
lib/index.js   宿主半边：4 条 exact 路由（state / ai / wallpaper?id= / diagnostics）
lib/ai.js      宿主半边：AI 主题生成，先走 DSH 已配置的模型，失败再走填写的 Key
lib/client.js  浏览器半边：手写免构建，window.__ModuleLoader__ 注册
test/          三个 Node 测试
```

浏览器半边是手写、免构建的，改完不需要编译；Node 半边是状态存储、壁纸库与 AI 路由。
